	</Card>
	<Card title="Scoped" icon="puzzle">

	</Card>
	<Card title="Agents for each harness" icon="setting">

	</Card>
	<Card title="Works with npx skills" icon="approve-check">
		Packs ship a plain build, so `npx skills` keeps working on the same repository.
	</Card>
